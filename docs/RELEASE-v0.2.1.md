# v0.2.1 发布说明

本版本调整飞书报告展示，保留 v0.2.0 的 cron 调度、查询口径、重试和防重行为。

## 展示变化

- 渠道、分组、重点模型延迟均使用 Markdown 表格，渠道、分组和模型名称加粗。
- 模型按分组显示标题，每组一张表：模型、成功次数、P50、P95；模型单元格不重复分组名称。
- 成功率超过95%显示绿色，恰好95%保留默认颜色。可配置的红色、橙色阈值优先判断；关闭 highlight 时也关闭绿色。
- 渠道仍按调用量取前20，错误码保留次数前三；分组仍只展示低于95%且有调用记录的分组，因此默认分组表不会出现绿色高成功率项目。
- 模型无成功记录仍省略；缺少耗时样本、分位数或查询失败时明确提示，不填造数值。延迟单位仍为秒。

## 升级与验收

不需要新增配置项，也不自动覆盖 `.env`、`config.toml` 或模型名单。沿用现有升级脚本，将目标版本设为 `v0.2.1`；特殊网络环境继续按需传入升级代理和构建网络参数。

数据库已缓存的定时报告不会按新格式重新渲染。验收请选择新的计划或普通预览；不要为看样式随意强制重发。飞书扩展颜色在其他 Markdown 渲染器中可能不显示。

CI 验证测试、Docker 构建和 cron 集成；Ubuntu 现场还需检查实际版本、新报告表格、颜色和下一计划的真实投递。发布不自动更新运行中的容器。
